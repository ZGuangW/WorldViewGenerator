# 示例目录 / Examples

本目录包含世界观编年史生成技能的使用示例。

## 输出文件

触发技能后，系统会在当前工作目录生成以下文件：

| 文件 | 说明 |
|------|------|
| `world.md` | 模块一输出：世界观主体框架与时间轴 |
| `plots.md` | 模块二输出：各时间节点叙事内容 |
| `society.md` | 模块三输出：十六维度社会全景描述 |
| `chronicle.md` | 模块四输出：整合后的完整编年史 |

## 示例场景 / Example Scenarios

### 示例 1：奇幻世界观 / Fantasy

```yaml
Type: Fantasy
Timeline: 3,000 years
Core theme: Rebuilding after Ragnarök
Trigger: "帮我构建一个奇幻世界观，时间跨度三千年，核心主题是诸神黄昏后的文明重建"
```

### 示例 2：赛博朋克 / Cyberpunk

```yaml
Type: Sci-Fi (Cyberpunk)
Timeline: 500 years
Core theme: Human-AI coexistence after technological singularity
Trigger: "Build a cyberpunk worldview, 500 years, theme: post-singularity consciousness upload society"
```

### 示例 3：历史架空 / Historical Alternate

```yaml
Type: Historical Alternate
Timeline: 1,000 years
Core theme: Rise and fall of a universal empire
Trigger: "构建一个历史架空世界观，千年跨度，王朝兴衰轮回"
```

### 示例 4：末世 / Post-Apocalyptic

```yaml
Type: Post-Apocalyptic
Timeline: 200 years
Core theme: New world order after ecological collapse
Trigger: "Design a post-apocalyptic world, 200 years after biosphere collapse"
```

---

*使用技能后，生成的文件将保存至当前工作目录。*
*Output files are saved to the current working directory after skill execution.*
