# 示例目录

本目录包含世界观编年史生成技能的使用示例。

## 使用说明

触发技能后，系统会在当前工作目录生成以下文件：

| 文件 | 说明 |
|------|------|
| `世界观框架.md` | 模块一输出：世界观主体框架与时间轴 |
| `关键情节.md` | 模块二输出：各时间节点叙事内容 |
| `社会面貌.md` | 模块三输出：十六维度社会全景描述 |
| `编年史.md` | 模块四输出：整合后的完整编年史 |

## 示例场景

### 示例1：奇幻世界观

- **类型：** 奇幻
- **时间跨度：** 三千年
- **核心主题：** 诸神黄昏后的文明重建
- **触发语：** "帮我构建一个奇幻世界观，时间跨度三千年，核心主题是诸神黄昏后的文明重建"

### 示例2：科幻世界观

- **类型：** 科幻（赛博朋克）
- **时间跨度：** 五百年
- **核心主题：** 人机融合与意识上传
- **触发语：** "生成一个赛博朋克世界观，五百年历史，核心是意识上传技术带来的社会变革"

### 示例3：历史架空

- **类型：** 历史架空
- **时间跨度：** 一千年
- **核心主题：** 大一统帝国的兴衰轮回
- **触发语：** "构建一个历史架空世界观，时间跨度千年，主题是王朝兴衰"

*使用技能后，生成的文件将保存至当前工作目录。*
